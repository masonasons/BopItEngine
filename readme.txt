Welcome to BopIt Engine!
BopIt Engine is brought to you by Bryn and Acer.
BopIt Engine is a program designed to emulate BopIt toys as faithfully as possible to the originals! Here is a list of keystrokes with their touch gestures on Android.
Tab (two finger swipe right): switch to next bop it
Down arrow (single tap): Bop it
Left Arrow (swipe left): Pull it
Right arrow (Swipe right): Twist it
Enter (Swipe down): Spin it
Up arrow (Swipe up): Flick it
A (Two finger tap): Toggle auto pilot.
S (Three finger tap): Set autopilot speed.
dash/equals (two fingers swipe up and down): Change pitch/emulation speed Hold alt for bigger adjustments.
0: Reset pitch/emulation speed to normal
